## token： 
    LLM最小处理单元
    1、中文：1 个汉字≈1 个 Token，标点、字母也单独算
    2、作用：计费、限制长度、计算上下文都以 Token 为单位

## context上下文：
    1、模型一次能记住的对话 / 文本总长度上限
    2、超过上限：最早的内容会被截断遗忘
    3、日常表现：聊太久，模型忘了前面说的话

## system/user/assistant/tool：
    1、system（系统提示）：给模型定人设、规则、任务要求（全局指令）
    2、user（用户）：人类提问、输入内容
    3、assistant（助手）：模型输出的回答
    4、tool工具：模型思考时调用的工具

## temperature温度：
    控制回答随机性、创造力的参数，取值一般 0～1
    越接近 0：回答严谨、固定、逻辑强、重复度高（适合问答、编程、推理）
    越接近 1：回答发散、脑洞大、创意足（适合文案、创作、闲聊）

## hallucination幻觉：
    LLM 编造不存在、错误、虚假信息的现象。
    表现：瞎编人名、数据、文献、事实，语气还十分肯定。
    原因：模型只预测下一个字，不具备真实 “认知 / 记忆”，纯概率生成。

## top_k=20-30：
    llm从中选取数量范围内20-30的token
## top_p=0.5–0.7: 
    llm从中选取概率范围内50%-70%的token

## 一次对话请求的 messages 结构:
```json
    [
         {
            "role": "system",
            "content": "你是严谨的知识助手，不确定的内容不要编造，如实回答。"
        },
        {
            "role": "user",
            "content": "解释一下LLM幻觉如何规避？"
        },
        {
            "role": "assistant",
            "content": "..."
        },
        {
            "role": "tool",
            "content": "返回当前坐标，这里可以是具体的函数返回值"
        }
    ]
```

## 多轮对话，包含历史问答记录，模型可记住前文，完整交互结构：
```json
    [
        // 系统角色（全局规则，全程生效）
        {
            "role": "system",
            "content": "回答简洁专业，拒绝编造信息。"
        },
        // 历史对话1：用户提问
        {
            "role": "user",
            "content": "什么是Token？"
        },
        // 历史对话1：模型回复
        {
            "role": "assistant",
            "content": "Token是大模型的最小文本处理单元，用于计费和长度限制。"
        },
        // 历史对话2：用户追问
        {
            "role": "user",
            "content": "上下文窗口是什么？"
        },
        // 历史对话2：模型回复
        {
            "role": "assistant",
            "content": "上下文窗口是模型单次能记忆、处理的Token最大长度。"
        },
        // 当前最新提问（模型需要回答的内容）
        {
            "role": "user",
            "content": "怎么降低模型幻觉？"
        }
    ]
```
## 模型为什么会受上下文和参数影响
    LLM 采用自回归逐 Token 生成的工作方式，上下文是模型的全部信息来源，决定了生成内容的语义方向与知识依据，长度超出窗口上限还会造成内容截断、对话失忆；而 temperature、top_p 等采样参数，控制模型从候选词概率池中挑选 Token 的规则，影响回答的严谨度、随机性与创造力，二者分别从输入信息和生成策略层面，共同决定了模型最终的输出结果。
