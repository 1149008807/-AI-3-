## 让模型根据自然语言生成表单 JSON，并在 Node 中成功解析。
    系统角色：你是一个前端表单 JSON 配置生成器。你只能输出合法 JSON，不要输出 Markdown、解释、注释或多余文字。
    输入：帮我生成一份前端AI开发的个人简介数据
    
    样本案例：输出：{"name":"","skill":"","desc":""}格式
    输出：json格式表单

## prompt常见格式要求
    1、角色定位：你是一名xx，你擅长xx
    例子：你是一名资深前端AI应用开发工程师，精通Vue3/React、TS、大模型接口对接、RAG应用开发。

    2、思维链式：核心原理：不让AI直接给答案，让AI分步思考、分步推导，大幅降低逻辑错误、数据错乱、幻觉问题。
    例子：请你一步步思考，分步推导，先梳理逻辑，再给出最终结果

    3、给大模型少样案例
    例子：输出：{"name":"","skill":"","desc":""}格式
    
    4、**接口强约束**：强制JSON格式，适配前端解析渲染
