## SSE原理
    SSE（Server-Sent Events，服务器推送事件）是一种基于 HTTP 的服务器向客户端单向推送数据的技术。
    1、单向：服务器-客户端
    2、基于http请求、使用 HTTP/1.1 的持久连接（Keep-Alive）、最大连接数受http影响
    3、自动重连

## 与WebSocket相比

| 特性 | SSE | WebSocket |
|------|-----|-----------|
| 通信方向 | 单向（服务器→客户端） | 双向 |
| 协议 | HTTP/1.1 或 HTTP/2 | ws:// / wss:// |
| 自动重连 | 内置 | 需手动实现 |
| 二进制数据 | 需 Base64 编码 | 原生支持 |
| 最大连接数 | 受 HTTP/1.1 连接数限制 | 更高（基于 TCP） |
| 浏览器支持 | 所有主流（除 IE） | 所有现代浏览器 |
| 实现复杂度 | 非常简单 | 中等 |
